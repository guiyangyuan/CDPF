# 一页选题决策：优先评估受控实验研究路线

日期：2026-09-13。筛查起点：`9b6e7d2`。本轮是选题与方案交付，零新训练、零GPU推理、未连接服务器、未修改模型或论文。H1仍停止，不重新启动。

**决定：可靠性蒸馏不进入实现；优先保留“文本知识增益的受控归因与成本研究”作为投稿选题候选。** 这是一条实验研究路线，尚未确认能满足学校及目标期刊要求，也不是已经发现了新算法。学校是否要求方法创新的问题已询问，未答复时不默认接受该路线、不启动新增训练。

## 建议题目与可以检验的贡献

暂定：**《少样本CLIP文本知识增强的收益来源：聚合、蒸馏与融合的受控研究》**。

三个研究问题：①固定描述均值的简单融合能贡献多少收益？②信息与参数预算匹配后，层级相对平面还有多少增益？③蒸馏对学生的收益是否能转化为最终融合收益？额外测量训练时间、推理延迟和峰值显存，避免用参数量代替实际效率。

已有探索证据：简单融合相对CoOp的平均配对ΔHM为UCF +4.35、DTD +6.95、Aircraft +4.06个百分点，各3/3种子正向；完整模型KD融合ΔHM分别+1.14、−0.49、−1.16。它们支持继续问上述问题，但不能证明整个领域的复杂方法无效。所有旧测试集均已被查看，必须标为探索证据。见[证据清单](EVIDENCE.md)。

与接近工作的可能区别是“同实现、同描述、同预算的归因及部署成本证据”，不是新聚合器、提示加权或新蒸馏损失。AAPE、ADK、CAPEL和2SFS已有相关方法和分析，见[逐项文献边界](SOURCES.md)。本次有限检索没有证明该实验问题无人研究。

## 最小实验与停止条件

先在本机完成数据/配置清单、指标口径和成本工具设计。拟用 **OxfordPets与EuroSAT** 作新增确认域：前者细粒度对象，后者遥感；按任务类型选择，未读取其新成绩。两者已有loader和描述文件，但图像根目录、划分、完整性与历史接触情况尚未核验，因此现在不具备运行条件。

若路线与准备均通过，首批仅2数据集×seed1×4个训练配置=**8次训练**；固定主对照为CoOp、参数匹配平面KD1、层级KD0、层级全KL KD1；简单融合复用CoOp。层级全KL配置统一命名为 `hier_kl1`，避免与已失败的H1损失假设混淆。最多2 GPU小时，先达到次数或时间上限即停；无损失搜索、无融合调参、无旧H1重跑。详见[最小协议](MINIMAL_PROTOCOL.md)。

首批检查技术可行性，**不以“简单方法必须赢”筛选结果**。确认研究若进入三种子，应一次冻结完整24个训练格（包含首批8格），不因seed1符号改变矩阵或删数据集。这24格只是计划，当前未授权执行。第二描述来源、外部作者方法和成本实验另列缺口，不能将8或24次训练冒充完整投稿材料。

若学校明确要求新算法，本轮B不作为最终论文方向；若外部对照或独立确认无法落地，停止扩量；若结果改变原判断，修改研究结论而非选择分支保住故事。没有具体增量问题时，不追加第三个临时选题。

**下一件具体工作：**核验Pets/EuroSAT的本机数据与划分、冻结一个外部方法的实现和适配差异、形成统一结果表及成本采集规范；这一步无需开卡。学校/期刊是否接受实验研究需在新增GPU支出前明确。论文和Overleaf仍暂不改动。
