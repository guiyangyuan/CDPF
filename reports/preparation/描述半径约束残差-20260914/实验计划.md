# 描述半径约束残差：下一步实验计划

## 要解决的问题

融合对齐残差在 DTD seed1 上把 Base 提高3.70个百分点，却让 Novel 下降7.37个百分点。事后缩放诊断表明，小幅残差仍包含有用方向，但固定系数来自已经查看过的 Novel 结果，不能成为方法。下一步让残差幅度由每个类别自己的描述分布决定。

## 候选方法

对类别 `c` 的20条冻结CLIP描述向量计算均值和均方根半径：

`r_c = sqrt(mean_v ||d_cv - mean_v(d_cv)||²)`。

当前适配器仍输出图像条件原始文本残差 `Δ_xc`。用平滑的语义信赖域限制其长度：

`Δ̂_xc = r_c · tanh(||Δ_xc|| / r_c) · Δ_xc / (||Δ_xc|| + ε)`。

最终保持：

- `F = 0.5(S+M)`；
- `Z = F + scale · image · Δ̂`；
- `L = CE(S,y) + CE(stopgrad(F)+R̂,y)`。

半径在 Novel 推理时用新类别自己的描述重新计算。没有全局0.25系数、门控阈值、额外损失权重或Novel图像；学生分支和20轮预算保持不变。

## 快速执行顺序

1. **本机CPU实现。** 只增加一个边界函数和一个新trainer/config；不改现有已验证入口。
2. **五项定向检查。** 验证残差范数不超过描述半径、零残差仍为零、学生更新与旧模型一致、Novel类别会重建半径、保存重载保留方法身份。不跑全套测试。
3. **旧checkpoint零训练筛选。** 加载刚完成的融合对齐残差权重，只重新导出有半径约束的Base/Novel预测。若HM不高于F，或Novel比F低超过1个百分点，立即停止。
4. **DTD seed1训练。** 只有零训练筛选通过才训练一次。要求HM高于同模型F，Novel相对F下降不超过1个百分点，并核对S/M/F与当前seed1参照一致。
5. **DTD seed2/3。** seed1通过后才补两次训练；要求平均HM增益为正、至少2/3种子为正、平均Novel下降不超过1个百分点。
6. **UCF101独立确认。** DTD全部通过后才运行seed1；seed1通过再补seed2/3。公式和判定规则在看到任何UCF101新输出前冻结。

最多6次新训练；前一阶段失败就停止。零训练重载不计训练次数。

## 论文判断

只有UCF101三种子也通过，才能把它作为候选方法贡献。即使通过，也需要与PromptSRC、SAR、Prompt-OT以及描述选择类方法说明差异。若零训练筛选失败，就说明“语义半径”没有抓住有效尺度，本方向在不花训练成本的阶段结束。
