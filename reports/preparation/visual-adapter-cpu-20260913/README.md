## 实际实现

在冻结CLIP图像特征后加入类别共享的残差MLP；输出直接参与CoOp和固定描述均值两个分类分支。固定描述CE可通过分类路径更新适配器，CLIP和描述编码不训练，CoOp上下文由CoOp CE更新。新开关默认关闭；开启时限定为CoOp、描述均值、无旧查询适配器/KD的原型，避免把多个新变量混在一起。

两层均无bias，瓶颈64维、残差系数0.2、升维层零初始化，初始化随机数隔离。ViT-B/16的512维特征下新增65,536个参数；加上4个CoOp上下文token共67,584个可训练参数。参数少只说明规模，不代表已测得训练速度或精度优势。

三组统一16-shot、20轮总训练预算：A为简单融合；B加入普通视觉适配，描述CE权重0；C与B同参数，描述CE权重1。A/B/C仅上述两个配置项不同。完整参数与本机初始化说明见[使用文档](../../../docs/VISUAL_ADAPTER_PROTOTYPE.md)和[有效配置核对](config-verification.json)。

模型保存包含提示和两层适配器，以及优化器、调度器状态；开启适配器时使用format 3模型签名，记录宽度、系数、初始化、作用位置和描述CE权重。Base→Novel重载保留共享参数，仅重建类别文本。旧checkpoint仍需其原冻结源码；没有放宽代码哈希校验。
