## 本轮实际改了模型什么

CoOp_TextDetail保留类别名作为适配器输入基础，用冻结CLIP的图片/描述相似度计算类内softmax权重。attentive直接加入加权描述隐藏特征；centered加入加权结果相对均匀描述均值的偏差。两者共用原512→64→512两矩阵，无新可训练头，仍67,584参数。学生SGD和残差AdamW0.001恒定lr保持不变。旧静态描述模型、模板、训练样本均未改。

这保留的是类别名输入，不保证类别名路径训练后的输出保持原样；两新模型重新从CLIP训练。学生S只接收自身CE。公式、对照、+1pp开发条件在训练前固定，见[方案](../../../docs/TEXT_DETAIL_PILOT.md)、[错例依据](../../diagnostics/text-adamw-errors-20260914/README.md)、[冻结源码cd109fe](https://github.com/guiyangyuan/textconsistency_v2_tune/commit/cd109fe6d982b5d6d5dada9f6a413e80e89846ec)。描述注意力、残差和适配本身不作为已证明的原创贡献。
