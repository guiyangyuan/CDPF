# 类别语义可靠性加权方案

## 问题

当前稳定信号来自学生提示分支 `S` 与均值描述分支 `M` 的固定概率/分数融合，但 Aircraft 的图片加权确认显示不同种子和类别的收益不一致。逐图片门控、融合残差、半径约束、描述子空间、类别关系约束和跨数据集校准门控均没有形成稳定收益。下一步需要先判断差异是否主要发生在类别层面，再决定是否值得学习可迁移的类别可靠性。

## 与已有工作的边界

- TaskRes直接在冻结文本分类器上学习任务残差，因此本方案不把“分类器残差”作为贡献。
- LP++为每个已见类别学习视觉/文本原型的融合乘子，因此本方案不能把“类别融合系数”本身作为贡献。
- SHIP从类别文本生成伪视觉特征；AAPE按图片聚合自然语言提示并蒸馏到提示生成器。因此本方案不生成伪视觉特征，也不再训练逐图片聚合器。

只有下面的 **Base类别规律到Novel类别的零标签迁移** 才可能形成区别：用冻结文本空间计算每个类别的描述一致性、类别名对齐和跨类判别间隔，在Base类上学习低容量可靠性映射，然后仅凭Novel类别文本预测融合权重。Novel图片和标签均不得参与权重拟合。

## 分阶段验证

1. 必要性上界：对现有DTD、UCF101、OxfordPets逐样本`S/M`输出做类别权重两折检验。若类别权重在留出图片上不能稳定优于训练折标量，立即停止，不开GPU。
2. 可迁移性探针：必要性通过后，一次性导出冻结的类别名和描述嵌入。只在Base类上拟合固定的低容量映射；DTD作为开发数据，另选未参与公式选择的数据集做独立确认。
3. 正式实验：只有可迁移性探针通过，才把权重计算接入推理并跑三种子Base/Novel。所有对照共用checkpoint和逐样本输出，避免重复训练。

## 预期公式

对候选类别 `c`，由冻结文本特征 `x_c` 得到 `alpha_c=sigmoid(w^T x_c+b)`，并计算：

`Z_ic=(1-alpha_c) S_ic + alpha_c M_ic`。

`x_c`只包含事前固定的三类统计：多描述与均值描述的类内余弦一致性、多描述均值与类别名的对齐、该类别描述均值相对其他类别的最近邻间隔。映射使用强正则的线性模型，容量与类别数无关。任何使用Novel图片置信度、Novel标签或Novel最优权重回归目标的版本都不属于正式方法。

## 风险

该方向仍与LP++的类别系数有邻近性。即使实验涨点，也只能在“文本可靠性从Base类迁移到Novel类”得到直接对照支持后讨论方法贡献。若必要性或迁移性阶段失败，投稿方案应回到已稳定的简单融合和更完整的数据集/基线证据，不继续叠加门控。
