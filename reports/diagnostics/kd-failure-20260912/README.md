# KD 学生退步：本机归因与后续决策

2026-09-12。本轮使用[已完成的九组GPU验证输出](../../experiments/validation-probe-20260912-42527/README.md)，完成1,500条记录的本机分析、公式核验和文献核对。没有连接服务器、加载模型训练或执行优化器；论文未修改。

**结论：学生更接近教师，同时在Base验证上退步。错误教师对应的退步风险明显更高；全分布KD也可能压低原本正确学生的目标类别置信度。以上支持进一步检查训练目标，但尚不能证明训练轨迹中的因果机制。只保留一个NCKD机制对照问题，没有确认新的论文创新候选。**

## 1. 学到了教师，并不等于学得更好

S0/S1分别是同协议下不使用/使用KD的旧完整方法学生，T是完全相同的教师；温度2、KD权重1。以下准确率差为三个种子均值，KL为该温度下乘以T²后的验证样本均值。

| 数据集 | S1−S0准确率（百分点） | S0→S1 新错/纠正记录 | 新错时教师也错 | 与教师KL：S0→S1 | 与教师top1一致率：S0→S1 |
|---|---:|---:|---:|---:|---:|
| UCF101 | −4.74 | 46 / 17 | 27 / 46 | 0.9201 → 0.2605 | 85.95% → 88.89% |
| DTD | −1.74 | 17 / 12 | 14 / 17 | 1.8256 → 0.4368 | 73.61% → 78.13% |
| Aircraft | −2.50 | 61 / 46 | 51 / 61 | 0.6777 → 0.1543 | 43.67% → 53.67% |

KL分别降低71.69%、76.07%、77.23%。三数据集学生NLL均变差，预测熵均上升，logit标准差向较低的教师标准差靠近，详细数据见[六分支统计](evidence/branches.csv)。这些是同一批最终checkpoint的端点比较，不能叫作“训练曲线”或把变动全部归因于某一种梯度机制。

合计新错124条、纠正75条，净少判对49条；其中92条新错对应教师也错，66条新错的S1错误类别恰好与教师相同。同时有35条纠正发生在教师top1错误的记录上。三种子的图片会重叠：1,500条是记录数，只有1,280张唯一图片；不能当作1,500个独立样本做显著性宣称。S1−S0并非每个种子都为负：九组中七组下降、一组持平、一组上升，逐种子均保留。

## 2. 教师错误是强关联，但不能直接推出一个可靠门控

在S0本来正确的记录中，分组风险如下。分母是各组自己的记录数，避免仅用“92/124”误判风险。

| 数据集 | 教师错：S0正确记录中新错比例 | 教师对：同口径新错比例 |
|---|---:|---:|
| UCF101 | 27/53 = 50.94% | 19/488 = 3.89% |
| DTD | 14/35 = 40.00% | 3/185 = 1.62% |
| Aircraft | 51/89 = 57.30% | 10/137 = 7.30% |

这说明最终教师错误与学生退步强相关；不证明最终教师的这一次错误就是训练时发生退步的原因。验证图像并不是KD训练时的输入，且缺少教师/学生在训练过程中的逐步状态。

固定置信度分箱为[0,.5)、[.5,.8)、[.8,.95)、[.95,1]，只作描述，没有搜索阈值。合计教师最大概率≥.95的304条记录仍有2条错误；<.5组有84条新错，也有52条纠正。教师置信度区分其正确性的三seed平均AUC为UCF .863、DTD .885、Aircraft .797；它有信号，但不等于完美可靠性。跨数据集原始置信度尺度差别很大，不能从这些验证标签直接拟合一个阈值再宣称泛化。

全部[四种正确性组合](evidence/cohorts.csv)、[置信度分箱](evidence/confidence-bins.csv)、[逐类计数](evidence/by-class.csv)、[逐图记录](evidence/by-sample.csv)均保存；不按最有利类别或seed筛选报告。

## 3. 全分布KD包含置信度约束

两版历史源码的loss函数完全相同：学生CE、教师CE、温度2的全分布KL，教师在KD项中detach。对一个样本的学生logits z，令p=softmax(z/T)、q=softmax(t/T)，则KD梯度为 `T(p−q)`；CE梯度为 `softmax(z)−one_hot(y)`。这里是**输出logit空间的导数**，不是prompt参数梯度。

在S0与教师都正确的记录中，KD单独使目标logit向下的比例（三seed均值）为UCF77.21%、DTD94.73%、Aircraft84.66%。教师top1正确，仍可能要求学生降低对真值的置信度。S0所有记录中，CE与KD的logit梯度内积为负的比例分别68.14%、70.49%、56.50%。此处“向下”只表示该logit的局部负梯度方向，不保证最终argmax或prompt更新也如此。

采用[DKD原文的恒等分解](https://arxiv.org/html/2203.08679v2#S3.SS1)，全分布KL可拆为目标类/其余类的二元KL，以及按教师非目标质量加权的非目标类条件KL。本轮验证该恒等式及其导数，没有提出新的分解公式。仅保留非目标条件KL（NCKD）的已知数学控制在S0端点降低上述logit冲突比例至16.83%、5.90%、4.83%；其目标logit导数为零是定义带来的性质，不是已训练方法涨点证据。

不能由此认定“删掉目标项就解决问题”：原KD值中加权非目标项仍占67.39%、59.49%、82.69%；错误教师也会提供错误的非目标类别关系。S1端点上NCKD与CE依然有38.07%、29.17%、30.00%的logit冲突。真实参数梯度还有网络Jacobian，不能由logit空间点积符号推断。
