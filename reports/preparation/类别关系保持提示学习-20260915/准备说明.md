# 类别关系保持提示学习：DTD 先导准备

CPU 实现与固定协议已经完成，当前不需要开 GPU。

- 源码提交：`1e9927b8bce411fb03c7bb2add43f64e7548b262`
- 训练上限：2 次；匹配基线与关系保持各 1 次。
- 评估：每个 checkpoint 分别重载 DTD Base 与 Novel 测试集。
- 唯一实验差异：`RELATION_WEIGHT=0` 与 `1`。
- 可训练参数：两组均为 ViT-B/16 的 4×512=2048 个共享提示参数。
- 推理：两组都使用 `F=0.5(S+M)`，新方法没有额外推理参数或计算。
- 停止规则：只有关系保持相对基线 HM 严格为正且 Novel 不下降，才准备新数据集；否则停止。

正式运行前需在 AutoDL 实例将 GitHub 的 `1e9927b8bce411fb03c7bb2add43f64e7548b262` 部署成只读 release，核对 CUDA、DTD 样本摘要、CLIP SHA、源码摘要和空输出目录。当前协议只记录未来命令，尚未连接服务器、加载真实模型或产生准确率。
