usage: train.py [-h] [--root ROOT] [--output-dir OUTPUT_DIR] [--resume RESUME]
                [--seed SEED]
                [--source-domains SOURCE_DOMAINS [SOURCE_DOMAINS ...]]
                [--target-domains TARGET_DOMAINS [TARGET_DOMAINS ...]]
                [--transforms TRANSFORMS [TRANSFORMS ...]]
                [--config-file CONFIG_FILE]
                [--dataset-config-file DATASET_CONFIG_FILE]
                [--trainer TRAINER] [--backbone BACKBONE] [--head HEAD]
                [--eval-only] [--model-dir MODEL_DIR]
                [--load-epoch LOAD_EPOCH] [--no-train]
                ...

positional arguments:
  opts                  modify config options using the command-line

options:
  -h, --help            show this help message and exit
  --root ROOT           path to dataset
  --output-dir OUTPUT_DIR
                        output directory
  --resume RESUME       checkpoint directory (from which the training resumes)
  --seed SEED           only positive value enables a fixed seed
  --source-domains SOURCE_DOMAINS [SOURCE_DOMAINS ...]
                        source domains for DA/DG
  --target-domains TARGET_DOMAINS [TARGET_DOMAINS ...]
                        target domains for DA/DG
  --transforms TRANSFORMS [TRANSFORMS ...]
                        data augmentation methods
  --config-file CONFIG_FILE
                        path to config file
  --dataset-config-file DATASET_CONFIG_FILE
                        path to config file for dataset setup
  --trainer TRAINER     name of trainer
  --backbone BACKBONE   name of CNN backbone
  --head HEAD           name of head
  --eval-only           evaluation only
  --model-dir MODEL_DIR
                        load model from this directory for eval-only mode
  --load-epoch LOAD_EPOCH
                        load model weights at this epoch for evaluation
  --no-train            do not call trainer.train()
