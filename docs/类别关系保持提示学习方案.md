# 类别关系保持提示学习方案

## 目标

现有残差与视觉适配模块直接用 16-shot Base 标签学习额外参数，多次实验表现为 Base 上升而 Novel 下降。新方案不增加可训练参数，通过冻结类别描述提供的类间关系约束共享 CoOp 提示，减少提示对 Base 类别关系的扭曲。

## 固定方法

对当前训练类别，令学习提示编码并归一化后的文本原型为 `T∈R^(C×D)`。令每类有效描述编码先求均值、再归一化后的冻结原型为 `D∈R^(C×D)`。去掉相似度矩阵对角线后计算：

`L_rel = mean_{i≠j} ((T T^T)_{ij} - stopgrad(D D^T)_{ij})²`

训练目标固定为 `L = CE(S,y) + λ_rel L_rel`，先导实验只比较 `λ_rel=0` 与 `λ_rel=1`，不搜索权重。推理仍为 `F=0.5(S+M)`，不添加门控、残差、参数或推理计算。

## 实现边界

- 新增独立 trainer，避免把探索损失混入历史 trainer。
- 两组使用相同 trainer、初始化、数据、优化器、训练轮数和推理分支，只改变 `λ_rel`。
- 描述原型保持冻结；关系损失只更新共享 CoOp context。
- checkpoint 和运行清单记录公式、权重及参数数量，禁止把两组权重互相加载。
- 新增配置默认为 `0`，历史 trainer 的数值路径不改变。

## 快速验证协议

CPU 阶段只运行两项针对性测试：纯张量公式/梯度，以及 tiny-CLIP 真实 trainer 的匹配初始化、一步更新和身份记录。随后准备 DTD seed1、16-shot、ViT-B/16、FP32、20 epochs 的两次训练命令。

GPU 先导只运行匹配基线和 `λ_rel=1` 各一次。若新方法相对基线的 HM 严格为正且 Novel 不下降，才准备独立数据集；否则停止该候选。DTD 属于开发数据，不作为独立确认。
