## GPU阶段

同一实例切换到GPU后执行：

```bash
cd /root/autodl-tmp/textconsistency/releases/扩展验证-20260915-8f54900
export PYTHONPATH="$PWD:$PWD/Dassl.pytorch"
python scripts/repro/执行扩展验证.py \
  --data-root /root/autodl-tmp/textconsistency/data \
  --output-root /root/autodl-tmp/textconsistency/runs/扩展验证-EuroSAT-seed1-20260915-8f54900 \
  --dataset eurosat --seeds 1 --execute
```

只有固定均值概率融合的HM严格高于CoOp，且Novel相对CoOp不低于−0.5pp，才补EuroSAT seed2/3。首轮失败时保留负结果并停止，不修改alpha、温度、描述、轮数或门槛。
