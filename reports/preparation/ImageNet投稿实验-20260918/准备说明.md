# ImageNet 投稿实验准备说明

更新时间：2026-09-18

## 当前状态

ImageNet 的代码、类别映射、描述覆盖和真实图像目录均已准备完成。服务器已严格核验 1,281,167 张训练图像、50,000 张验证图像和 1000 个 train/val 类别目录，并在最新 release 中生成 16 条冻结实验命令。GPU 尚未启动，因此目前还没有 ImageNet 实验结果；无卡实例已关机。

本轮已完成：

- 固定 CoOp 官方提交 `ff61507c790454bce7c5052c3ac39e60772f1f89` 的 `classnames.txt`，共 1000 个 synset，SHA256 为 `89e0b642c6697a3a43a06a2bb65f9fefb3ca295ccc5f4ba9ce385f1a3a58c629`。
- 逐 synset 核对 998 个描述键。数量差异来自两个官方重复显示名称：`missile` 对应 `n03773504`、`n04008634`，`sunglasses` 对应 `n04355933`、`n04356056`。1000 个 synset 均能取得至少 20 条描述，没有默认提示词回退。
- 修复描述顺序清单对重复显示名称的错误限制。现在用 `class_index` 保留四个 synset 的独立身份，不把同名 synset 合并成一个类别。
- 固定三种子完整实验：3 次 Base 训练、6 次 CoOp Base/Novel 检查点复评、6 次冻结融合评估和 1 次汇总，共 16 条命令。
- 固定 CLIP ViT-B/16、16-shot、N_CTX=4、20 epochs、seed 1/2/3、全局 `alpha=0.5`；不搜索权重、温度、描述、轮数，不按结果停跑或删种子。
- 新增一次性数据核验：严格检查 1000 个 train/val 类别目录、1,281,167 张训练图像、50,000 张验证图像、每个 Base 类至少 16 张训练图像，以及类别名称和描述文件哈希。
- 新增可恢复的公开归档解压入口：训练集按1000个synset流式展开，验证集用官方devkit映射到synset目录；文件采用原子写入，中断后重复运行会复用已完整写入的图像。
- 23 项针对性单元测试与语法编译通过。
- 数据盘从50GB扩到200GB后完成公开归档解压；严格核验得到1000个类别目录、1,281,167张训练图像、50,000张验证图像、训练每类732至1300张、验证每类50张，目录完全匹配。
- 提交`45ff8ba`的服务器release和最新计划均已生成，模型源码摘要仍为`e4d4343f31b7cdbcccd3b81ddc99536080c62e573783b27c9366a3c64a7892db`；无卡实例已确认关机。

机器可读结果见[静态核验](静态核验.json)和[服务器准备收据](服务器准备收据.json)。

## 数据目录要求

CoOp 数据加载器要求以下结构：

```text
/root/autodl-tmp/textconsistency/data/
└── imagenet/
    ├── classnames.txt
    └── images/
        ├── train/
        │   ├── n01440764/
        │   └── ... 共1000个synset目录
        └── val/
            ├── n01440764/
            └── ... 共1000个synset目录
```

AutoDL 已提供发布方标为 `image-net.org` 的公开只读镜像，路径为 `/root/autodl-pub/ImageNet/ILSVRC2012`，包含138G训练归档、6.3G验证归档和2.5M官方devkit，因此不需要再登录官网下载或把归档复制到数据盘。公开镜像标称157.56GB；其自带说明估计解压后的train/val约130GB。

实例数据盘已新增150GB，当前总容量200GB，费用为**1.00元/日**，即使关机也计费。解压前可用165GB，完整解压和核验后约剩19GB。账号密码只在官方页面或当前终端交互使用，没有写入命令、日志、脚本、Git或报告。

## 无卡阶段命令

服务器拉取本提交后，在仓库根目录运行：

```bash
/root/autodl-tmp/textconsistency/.venv/bin/python -B scripts/repro/准备ImageNet投稿实验.py 安装类别名称 \
  --data-root /root/autodl-tmp/textconsistency/data
```

付费扩容确认并生效后，从只读公开归档可恢复解压：

```bash
/root/autodl-tmp/textconsistency/.venv/bin/python -B scripts/repro/准备ImageNet投稿实验.py 解压公开数据 \
  --data-root /root/autodl-tmp/textconsistency/data \
  --public-root /root/autodl-pub/ImageNet/ILSVRC2012 \
  --minimum-free-gib 160
```

解压器结束时会自动执行完整核验，也可以单独复核：

```bash
/root/autodl-tmp/textconsistency/.venv/bin/python -B scripts/repro/准备ImageNet投稿实验.py 核验 \
  --data-root /root/autodl-tmp/textconsistency/data \
  --output /root/autodl-tmp/textconsistency/setup-logs/ImageNet投稿实验-20260918/数据核验.json
```

核验通过后，在服务器本机生成带服务器绝对路径和文件哈希的执行计划：

```bash
/root/autodl-tmp/textconsistency/.venv/bin/python -B scripts/repro/准备ImageNet投稿实验.py 计划 \
  --data-root /root/autodl-tmp/textconsistency/data \
  --output-root /root/autodl-tmp/textconsistency/outputs/ImageNet投稿主实验-20260918-45ff8ba \
  --plan-path /root/autodl-tmp/textconsistency/setup-logs/ImageNet投稿实验-20260918/执行计划45ff8ba.json \
  --python /root/autodl-tmp/textconsistency/.venv/bin/python
```

以上步骤均已在无卡模式完成。执行计划由提交`45ff8ba`的服务器release生成，包含服务器绝对路径和逐文件哈希；提交`099f364`生成的旧计划不执行。

## 开卡后的唯一入口

数据核验和计划都通过后再开启 GPU，并运行：

```bash
/root/autodl-tmp/textconsistency/.venv/bin/python -B scripts/repro/准备ImageNet投稿实验.py 执行 \
  --plan-path /root/autodl-tmp/textconsistency/setup-logs/ImageNet投稿实验-20260918/执行计划45ff8ba.json
```

执行器会在创建输出目录前再次核验数据、模型源码和计划文件；CUDA 不可用、输出目录已存在、源码变化或图像数量不正确时都会拒绝启动。每条命令单独保存中文日志，最终生成 `结果汇总.json`、`结果报告.md` 和 `执行状态.json`。

## 证据边界

- 当前已证明 ImageNet 数据、类别映射、描述资源和执行计划均就绪，但GPU训练尚未运行，因此不能报告ImageNet结果。
- 200GB数据盘的1元/日费用在实例关机时仍会继续；无卡小时费用已通过关机停止。
- 仓库中的旧 ImageNet V2_FG 日志使用不同方法、N_CTX 和损失配置，不能进入当前论文结果。
- ImageNet 完成前，论文仍按十数据集报告，不能把十数据集平均与标准十一数据集平均直接排名。
- 官方类别表的四个同名 synset共享同一组可读类别描述，这是官方显示名称造成的确定性映射，不是遗漏类别或人工补写描述。
