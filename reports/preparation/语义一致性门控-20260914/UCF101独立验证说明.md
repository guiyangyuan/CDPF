# UCF101 独立验证说明

## 执行顺序

1. 在 UCF101 Base 类训练 seed1，20 epochs，16 shots。
2. 导出同一检查点的 Base/Novel 逐样本 `S/M/F/R/Q/G`。
3. 只有 `G` 相对 `F` 的 HM 增益大于 0 且 Novel 准确率不下降，才训练 seed2、seed3。
4. 三种子要求平均 HM 增益大于 0、至少 2/3 个种子为正、平均 Novel 准确率不下降。

最多新增 3 次训练。seed1 失败时只消耗 1 次训练。

## 固定比较

- `F`：类别名与图片加权描述的简单融合。
- `U=F+R_hat`：未门控的半径约束残差，用作消融。
- `G=F+qR_hat`：语义一致性门控结果。

DTD 只用于提出和筛选公式。UCF101 是独立确认数据集，生成输出后不再调整公式、阈值或停止条件。
