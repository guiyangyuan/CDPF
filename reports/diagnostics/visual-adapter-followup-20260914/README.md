# 下一步候选：保护学生训练，学习描述纠错残差

## 为什么改训练目标

[上一轮固定实验](../../experiments/visual-adapter-westc-20260914/README.md)中，C描述分支从24%提高到28%，学生从32%降到31%，最终等权融合却从30.5%降到29%。源码显示：学生与描述共用适配后图像特征；训练分别优化学生CE和描述CE，没有直接优化最终融合CE。这是计算路径事实，尚不能据此证明存在梯度冲突。

本次只读取已归档logits，用[诊断脚本](diagnose.py)核验三个文件的SHA、类别与样本顺序、标签及原融合公式，计算固定分支组合；没有训练、拟合权重、搜索alpha或查看新测试集。命令：`python reports/diagnostics/visual-adapter-followup-20260914/diagnose.py`（依赖NumPy）。完整输出见[diagnostic.json](diagnostic.json)。

## 推荐的最小改动

1. **分开视觉路径。** 学生S继续用冻结CLIP原始图像特征和CoOp提示，按原学生CE训练；小适配器只服务纠错分支。新增损失不回传学生提示，避免再次用描述目标直接改变学生训练。
2. **描述从独立分类器改为纠错依据。** 计算同一固定描述文本上的“适配后分数−适配前分数”，作为残差R。适配器零升维初始化时R应为零，最终从学生预测出发。
3. **直接训练最终结果。** 用学生分数加R计算分类损失，让纠错分支针对学生当前输出学习；学生仍只接收自己的CE。目标是最终净改对图片多于改错图片，而不是单独D提高。

建议原型公式（未实施、尚未冻结成GPU协议）：

```text
f  = normalize(frozen_CLIP_image(x))
fa = residual_adapter(f)                 # 参数跨类别共享，沿用64维/.2尺度
S  = scale * f  @ learned_CoOp_text.T
D0 = scale * f  @ fixed_description_text.T
Da = scale * fa @ fixed_description_text.T
R  = Da - D0
Z  = S + R
loss = CE(S, y) + CE(stop_gradient(S) + R, y)
```

纠错系数建议先固定为1、不做权重扫描；CoOp和适配器在同一20轮内共同训练，不额外预训练学生20轮后再加20轮。描述特征固定，CLIP及logit scale冻结。仍仅用Base训练标签，Novel时换类别文本，复用同一适配器；不存在需要Novel标签的类别混淆矩阵。

梯度隔离与零残差起点只保证计算性质，**不保证训练后的最终准确率或Novel泛化不下降**。原始描述均值曾改善Novel；此方案只保留描述引起的修正量，可能损失那部分语义先验，因此必须保留简单融合对照。

## 实施与实验顺序

- **先做本机CPU原型。** 验证零初始化时Z=S、额外损失对学生提示梯度为零、匹配随机初始化/批次后的学生更新与原基线一致、适配器确实更新、冻结参数不变、完整保存重载、Novel类别数变化。完成后再冻结数据、种子、阈值及运行预算。
- **再做三组小规模训练。** ①原学生（同时导出其固定描述简单融合，作为额外零训练成本参照）；②学生保护＋普通类别名文本纠错；③学生保护＋详细描述纠错。②③同参数、同初始化规则、同预算，只替换冻结文本。先导建议仍用Aircraft seed1 Base验证，每组20轮，明确这是开发实验；不自动扩量。
- **继续条件应比上一轮更严格。** 必须比较学生单独、原简单融合、参数匹配的类别名纠错，不能只超过较弱的30.5%融合就宣布成功。建议③相对三者都至少+1pp才进一步确认；具体协议在新结果出现前固定，微小先导差异不是统计或论文结论。
- **有信号后再做确认。** 冻结方案后做多种子、Base/Novel/HM和未用于开发决策的数据集。Aircraft/DTD/UCF已用于研究决策，不能重新称作独立确认集；确认数据集须在看新结果前指定。还要加入相近作者方法的公平比较。失败则停止此候选，不用同一验证集无上限寻找融合权重。

没有为新方案启动或安排后台GPU队列。上一轮16.07分钟只是既有三组实验实测，不能当作新方案耗时承诺。

## 备选与原创性边界

单纯分离两分支后平均，可能减少干扰，但端点交叉组合没有显示超过学生的额外收益；只投影梯度需先证实共享参数上的冲突，而且已有相关方法；加入patch级局部属性对齐改动更大，暂不作为第一步。因此优先验证上述可隔离的纠错假设。

[CLIP-Adapter](https://arxiv.org/abs/2110.04544)已使用残差适配，[VDT-Adapter](https://arxiv.org/abs/2307.11661)已结合描述与适配器，[Logits DeConfusion（CVPR 2025）](https://arxiv.org/abs/2504.12104)已用残差结构消除类别间logits混淆。因此“适配器”“描述＋适配”“logits残差”都不能单独认定为原创。

这里要检验的是：**在保护学生训练的条件下，用可替换的描述文本方向学习有用的分类修正，能否超过类别名残差和简单融合，且保留Novel表现。** 这是候选贡献假设，尚无新成绩或足够新颖性证据。小规模结果有信号后再核对相近方法的完整公式与统一协议结果；不预先承诺发表。
