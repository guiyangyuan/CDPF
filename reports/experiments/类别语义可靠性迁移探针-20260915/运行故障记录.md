# 类别文本几何导出运行故障记录

本轮只在 AutoDL 无卡模式执行 CPU 文本编码。成功结果生成前发生过三次启动失败，均在正式导出前终止，没有产生可被迁移探针读取的结果文件。

1. 首次命令依赖 `/usr/bin/time`，但实例中不存在该程序，Python 导出器没有启动。
2. 第二次启动时，导出器未把发布目录加入 `sys.path`，因此无法导入仓库内的 `clip` 模块。该问题由提交 `1f61c49` 修复。
3. 第三次启动调用了上游 OpenAI CLIP 的 `clip.load()` 路径，而本仓库分支中的 `build_model` 需要额外的 `design_details` 参数，因此在编码前失败。该问题由提交 `ab35c84` 修复，导出器改为使用仓库兼容的加载路径。

最终成功运行使用的导出器源码 SHA256 为 `5f02b94846318246f8f062247e4c46a1a9b1e0b2442620b0f8603bb04ecf4092`，完整类别文本几何文件 SHA256 为 `efc58d6b842594b5ca6ecce3f6f4253fac0ec4926b6601254c87b95422f4fb90`。成功日志和服务器收据保存在同目录的 `服务器文本导出` 文件夹中。
