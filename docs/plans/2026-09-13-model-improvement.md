## 从现有代码得到的具体切入点

在[CustomCLIP.forward](../../trainers/coop_textconsistency_v2_fg.py)中，冻结CLIP得到的归一化图像特征直接用于学生与教师分类。在[ViewAggregator.forward](../../trainers/textconsistency_common.py)中，`fine_grained_proj`的残差结果只传给注意力查询，不回传为分类用视觉特征。现有MLP实际调整描述选择，不能据此声称视觉分类特征已被适配。这是已核对的计算路径，不是已证实的性能瓶颈或bug。

历史三种子结果支持保留描述信息：简单CoOp+固定描述均值的配对HM提升在UCF101/DTD/Aircraft均为3/3正向；层级和KD的额外价值不稳定。见[既有结果](../../reports/experiments/attribution-study-20260911-42527/README.md)。因此首个改动放到视觉分类路径，保留简单描述均值，暂不同时加入层级、蒸馏、动态融合等变量。

## 首选假设与最小结构

**假设：让少量Base训练图像学习共享的视觉残差，并用固定类别描述监督它，有机会提高细粒度类别区分，同时保留对Novel类别文本的兼容性。** 优先关注FGVCAircraft等细粒度识别；其历史成绩已参与决策，只能作为开发证据。冻结骨干不能创造其输出已丢失的局部细节，适配器是否足够有用必须实测。

候选计算路径如下，符号为草案，不表示代码已存在：

```text
f  = normalize(frozen_CLIP_image(x))
fa = normalize(f + rho * B(ReLU(A(f))))
zC = scale * fa @ learned_CoOp_text.T
zM = scale * fa @ fixed_description_mean.T
loss = CE(zC, y) + lambda_desc * CE(zM, y)
prediction = 0.5 * (zC + zM)
```

所有类别共享同一个小瓶颈适配器；描述编码固定，描述CE的梯度通过zM进入视觉适配器。CoOp提示通过zC更新。只使用Base的16-shot训练图像及标签，测试Novel时更换类别文本，继续用同一个适配器；不增加Novel支持集或标签。原图像编码器保持冻结。

第一版不做超参数搜索；实现前固定瓶颈宽度、残差系数、初始化、优化器与学习率，并写入配置及checkpoint身份。候选描述系数先取1，对照取0；训练均从同一冻结CLIP出发，CoOp与适配器合计20轮，而非在已训20轮CoOp上再训练20轮后称预算相同。适配器初始化应接近恒等映射，避免随机残差改变起点。

## 必须回答的两个模型问题

| 对照 | 训练改动 | 作用 |
|---|---|---|
| A：当前简单融合 | CoOp训练，固定描述均值参与推理 | 现有有效参照 |
| B：普通视觉适配 | CoOp+共享视觉残差，仅CE(zC)，lambda_desc=0 | 判断收益是否仅来自已有视觉适配器 |
| C：描述监督视觉适配 | 与B相同，加入CE(zM)，lambda_desc=1 | 判断描述监督在同等参数下是否还有增量 |

三组均保留CoOp分支、描述分支及相同0.5融合输出；B与C参数量、图像、描述、种子、训练预算和推理规则相同。先比较B−A及C−B，不把C只超过原来较弱的完整框架作为成功。A能否复用旧结果必须逐项确认身份与预算，否则独立重跑并保留原因。普通适配器按本仓库统一协议实现时，称CLIP-Adapter风格对照，不冒称作者原表复现。

先完成本机原型与CPU验证，再冻结小规模Base验证实验。是否继续的数值标准、运行格和预算在读取新结果前另行记录；本文件未创建GPU队列。Base验证涨点只能用于开发，最终必须看固定方案的Base/Novel/HM及多种子，并在未参与方案选择的数据上确认。若仅Base上涨而Novel明显受损，不宣称泛化改进；若要改为闭集少样本课题，需明确更换任务定义及对照。细粒度定位须在新结果前固定，不能事后挑获益数据集。

## 已知方法与候选贡献的边界

- [CLIP-Adapter](https://arxiv.org/abs/2110.04544)已使用视觉/语言分支瓶颈及残差融合；适配器本身是已有技术。
- [VDT-Adapter](https://arxiv.org/abs/2307.11661)已有视觉描述与少样本句子选择，且[作者仓库](https://github.com/mayug/VDT-Adapter)提供Base-to-New脚本。“描述+适配器”这个大标签不是独有贡献。
- [Tip-Adapter](https://github.com/gaopengcuhk/Tip-Adapter)的带标签支持集缓存可作为闭集少样本参照，但只有Base支持标签的缓存不能直接充当Novel类别分类器，因此当前不把它无条件接入Base-to-Novel主线。

合理组合已有方法可以成为候选，但需要说明针对的问题、实际机制差异，并超过相近方法及简单组合。当前公式只建立一个可检验的模型改动，不表示“描述监督视觉适配”已被查证为新算法。若C优于A但不优于B，先接受普通视觉适配有效、描述监督未显示额外价值的结论。若初步有稳定信号，再完成相近作者实现比较与必要改进，不能预先承诺录用。
