# 图片加权独立作用与新类别确认协议

日期：2026-09-14。用户要求先补“类别名＋均值描述”对照，确认图片加权的独立作用，再做多种子和新类别验证。本批不调整论文、温度、融合系数、瓶颈维度、学习率或训练轮数。

## 对照定义

- 类别名：原类别名共享文本残差。
- 均值描述：以类别名隐藏特征为锚点，类内有效描述经过相同下投影和ReLU后取均值。
- 图片加权：结构与均值描述相同，只把均匀权重替换为冻结CLIP图片与描述相似度的类内softmax权重。

三组均使用4个CoOp上下文、512→64→512共享残差、学生SGD、残差AdamW 0.001、16-shot、batch 16、20轮和相同数据增强，可训练参数均为67,584。均值描述和图片加权之间唯一的模型差异是描述权重是否依赖当前图片。

## 固定执行顺序

1. Aircraft seed1 Base开发验证集只训练一次均值描述，对照已经冻结的图片加权结果。
2. 图片加权必须比均值描述至少高1.0个百分点，即200张图上净多2张正确，才启动扩展批。
3. 通过后，从原始CLIP分别训练类别名、均值描述、图片加权的seed 1/2/3；均值描述seed1复用第一阶段模型。
4. 每个模型固定加载第20轮，在官方Base测试集和Novel测试集各导出一次。禁止按测试分数挑轮次、改参数、删种子或自动重试。

若第一阶段未通过，立即停止多种子与Novel扩展，并报告图片加权的独立作用未确认。

## 三种子判定

图片加权相对均值描述须同时满足：

- 三个种子的配对HM差平均至少+1.0个百分点；
- 至少2/3个种子的HM差为正；
- Novel准确率的三种子平均不低于均值描述。

类别名结果作为额外参照，不替代上述同结构均值描述对照。报告每个种子的Base、Novel和HM，以及三种子均值和样本标准差。同一种子内三组的样本顺序、类别顺序、学生S、固定描述M和简单融合F必须逐元素一致。

## 结论边界

第一阶段是已反复使用的Base开发验证集，只决定是否扩展。第二阶段使用官方测试划分，但Aircraft已参与此前项目研究，因此不是完全未接触的最终外部确认集。本批最多确认该结构在Aircraft上的独立作用，不能单凭一个数据集宣称达到投稿录用条件。
