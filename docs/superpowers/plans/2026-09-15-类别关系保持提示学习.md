# 类别关系保持提示学习 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不增加模型参数与推理开销的前提下，用冻结描述的类别关系约束 CoOp 提示，并准备 DTD seed1 两次匹配训练。

**Architecture:** 新 trainer 继承当前均值描述融合 trainer，训练时额外计算学习提示原型与冻结描述均值原型的非对角余弦关系矩阵 MSE。推理与现有简单融合完全一致；配置中的固定权重决定训练目标，模型身份与 checkpoint 严格绑定该权重。

**Tech Stack:** Python、PyTorch、Dassl、YACS、unittest、NumPy

**Spec:** `docs/类别关系保持提示学习方案.md`

## Global Constraints

- 不新增可训练参数，推理保持 `F=0.5(S+M)`。
- DTD seed1 先导仅比较 `RELATION_WEIGHT=0` 与 `1`，不搜索权重。
- 只运行两项针对性 CPU 测试，不运行全量测试。
- 所有新报告与计划文件使用中文名称。
