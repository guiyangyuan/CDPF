# 分离优化器后的三组验证：固定执行协议

2026-09-14。用户“继续下一步”授权实施、AutoDL开卡、固定训练、完整备份后关机及报告。研究目标仍为模型改进，不修改论文/Overleaf。本轮是已有Base验证集上的开发实验，不是独立确认或完整论文实验。

## 动机与本轮改动

上一轮短诊断仅在200张训练图上显示：SGD0.002拟合45.0%、AdamW0.001拟合75.5%。不能把训练拟合率当验证涨点，也不能单独归因于优化算法。本轮恢复完整16-shot训练、动态增强和学生共同训练，检查优化后的残差是否能泛化到未参与拟合的验证图。

模型公式、描述、结构、共享参数不变。学生只用自己的CE，SGD lr0.002/momentum0.9/wd0.0005，原cosine及1轮warmup不变；残差只用CE(stopgrad(S)+R)，单独AdamW lr0.001/betas0.9,0.999/eps1e-8/wd0.0005，恒定学习率无warmup。学生2048参数、残差65536参数，三组总计均67584。独立入口CoOp_TextResidual_AdamW，旧入口行为保留；两个优化器状态及学生scheduler完整保存，优化身份进入format5 checkpoint签名。

## 固定三组与数据

1. classname：单条类别名文本残差。
2. description：原始详细描述残差。
3. contrast：同一描述减去最近5个其他类别名均值后学习残差。

三组分别从同一原始CLIP/初始化规则重新训练20轮，不继承短诊断或上一轮训练残差。Aircraft seed1，Base50类，16-shot共800训练图，200验证图；ViT-B/16 FP32，batch16，原随机裁剪/翻转，最多20条描述；数据、CLIP、模板、训练源码及三份配置hash锁定。

3次训练+3次第20轮独立重载。训练NO_TEST=True，不挑中间轮；每次重载一次导出S/M/R/Z/F，Z=S+R，F=.5S+.5M。三组学生逐图S必须相同，作为原学生配对参照；未额外增加学生训练。No Novel/test inference。验证集已多次用于开发，后续需要新数据集/多种子确认，不能重新称作独立验证。

## 事前判断规则

- **主假设（近邻中心化）：**contrast.Z相对S、F、classname.Z、description.Z四者均至少+1pp（200张净多对至少2张），才支持进一步确认该候选。与之前同门槛。
- **次假设（详细描述）：**description.Z相对S、F、classname.Z三者均至少+1pp，支持继续检查原始描述在优化后框架中的价值。该次比较在新训练前登记；如果只有它通过，不把中心化宣称有效。
- 两个都是开发信号，不是显著性检验或录用门槛；所有正负结果同时保存，不选择最佳分支替代预定比较。若只有类别名提升，不能把普通文本适配的收益归因于描述机制。
- 一轮固定队列最多1GPU小时，无自动重试/扩量，不改融合权重、不扫学习率、不读取Novel挑设置。两组信号均不自动触发下一批。
