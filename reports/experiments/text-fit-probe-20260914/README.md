- 一次GPU编码得到固定中心裁剪图像特征及学生logits，CPU训练两个共享文本残差。两组均重置到同一个zero-up初始残差、同批次顺序、同200步、同模型和尺度，仅比较两组预定优化设置。学生已用16-shot训练过，不能称为4-shot新方法成绩。

- 正式诊断8.695秒，其中模型加载与缓存约7.513秒；400步优化均在CPU，无GPU反向训练。这个运行时长不含开机、部署、传输及备份，不是总计费时间。

**研究判断：**“模块完全没有拟合能力”的解释不被这次结果支持；原SGD配置在此受控诊断中更新明显偏弱。该结果不证明过去所有失败都由优化器导致，也不能排除新设置会过拟合。因此保留框架，下一项有价值的实验是给三个文本对照统一合理的残差优化设置，在固定验证协议下检查泛化及描述的额外贡献。单纯换优化器不构成方法创新。
