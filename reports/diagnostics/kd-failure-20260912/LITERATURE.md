# 针对蒸馏修补方向的文献核对

核对日期2026-09-12。检索围绕CLIP prompt蒸馏、教师可靠性、目标/非目标解耦、logit标准化与梯度对齐。以下均使用论文原文、作者摘要或正式会议记录；不是穷尽性新颖性检索。本轮没有运行作者实现或使用跨协议表格判断优劣。

| 来源 | 已有机制及核对范围 | 对本项目的约束 |
|---|---|---|
| [DKD，CVPR2022](https://arxiv.org/abs/2203.08679)；[方法§3.1–3.3及附录](https://arxiv.org/html/2203.08679v2) | 将KL分解为目标类别质量与非目标类条件关系，并独立设置两项权重 | 本轮分解直接引用该思路。仅用NCKD是一个已知组件控制，不是新算法；也不等于官方最优DKD配置复现 |
| [Logit Standardization，CVPR2024](https://arxiv.org/abs/2403.01427)；[完整方法§4](https://arxiv.org/html/2403.01427v1) | 分析共享温度下的尺度匹配限制，使用逐样本logit Z-score预处理 | “避免匹配教师置信度/尺度，只学关系”已有直接先例。学生logit标准差变小只是本项目观察，不能据此宣称证明了该论文的所有机制 |
| [ProGrad，ICCV2023](https://arxiv.org/abs/2205.14865) | 以零样本CLIP知识方向约束prompt的任务梯度更新；核对作者摘要及前轮正式会议来源 | 保护梯度方向已有先例。本项目只有端点logit导数，不能宣称复现其参数梯度证据 |
| [BiomedCoOp，CVPR2025](https://arxiv.org/html/2411.15232v2#S3.SS3) | 用描述相似度及MAD去除异常prompt，再以选择后的教师分布蒸馏；核对§3.3–3.4 | 过滤不可靠描述再KD已有近邻。它是医学BiomedCLIP场景，与“按样本teacher top1正确性二值门控”不完全相同，不把二者混称同一方法 |
| [CA-MKD，ICASSP2022](https://arxiv.org/abs/2201.00007) | 按教师对真值的预测能力度量可靠性并加权多教师蒸馏；核对作者摘要及既有原文记录 | 用标签评估教师质量并控制KD权重并非新概念；不同于仅以最大softmax作可靠性 |
| [AAPE，NeurIPS2024](https://arxiv.org/abs/2410.23698) | 图像对齐的描述聚合与表示蒸馏；本轮核对作者摘要，方法细节沿用[既有核对](../error-analysis-20260911/PRIOR_WORK.md) | 描述聚合加蒸馏已存在；对原复杂框架的独特性要求仍未解决 |
| [Beta-KD，2026-03预印本](https://arxiv.org/abs/2603.21426) | 从不确定性角度调节数据监督与教师监督；本轮仅核对作者摘要 | 置信度/不确定性控制蒸馏有更新工作；其多模态VQA设置不能当作本项目CLIP分类的同协议基线 |
| [TheProfessor，2026-06预印本](https://arxiv.org/abs/2606.23897) | PromptKD设置下比较多教师等权与置信度加权融合；核对作者摘要，包含单种子范围 | 普通多教师置信度融合已具近邻；它也不等于本项目受控三seed自然图像结果或录用结论 |

访问说明：部分CVF HTML返回403；DKD通过arXiv v2全文核对，Logit Standardization通过arXiv v1全文核对。最初尝试其不存在的v2 HTML返回404，随后按论文实际版本读取v1；访问失败不作为“没有先前工作”的证据。

本轮结论是**当前直观修补手段的先前工作重叠较高**，没有据此完成“某个新方法不存在”的证明。尤其不能把`CE + NCKD`、普通teacher置信度门控或logit Z-score重新命名后作为原创贡献。若继续研究，已知方法应当作为诊断/比较基线；有改进效果后仍须明确额外问题、区别和独立证据。
