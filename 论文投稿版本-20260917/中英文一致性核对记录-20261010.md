## 三、仍需在正式投稿前处理的事项

### P0：正式投稿 PDF、源码压缩包和在线 Overleaf 尚未同步

仓库中的“论文投稿版.pdf”和“论文投稿源码.zip”是在本轮及前次 ATPrompt/CuPL 修改之前生成的存档。**本轮修改的是 GitHub 内的源码文件，不等于已在 Overleaf 网页里重新编译。** 必须在 Overleaf 中使用最新 “Overleaf直接替换/pag.tex”、“Overleaf直接替换/cas-refs.bib” 及既有三张图片重新替换并编译，检查引用、编译警告、图表和页数，再导出新 PDF/ZIP。切勿把旧 PDF 直接当成已经更新的成品。

### P0：作者及投稿元数据仍是占位符

英文 “pag.tex” 中仍存在 Author Name、Advisor Name、邮箱、学校及地址占位符；期刊与通讯作者信息需要作者确认。还应按目标期刊要求补充相应声明。

### P1：代码可用性陈述与仓库可见性不一致

正文目前称相关代码和实验归档 “are available”，而 GitHub 仓库实际为 private。投稿前应决定公开仓库、提供匿名审稿链接或正式补充材料，并对应修订 Data and Code Availability。中文对照稿已备注这一风险，没有将其改写为已经公开。

### P1：文献对比表的强调格式容易误导

[table_published_hm.tex](最终提交源码/table/table_published_hm.tex) 中，TextConsistency 的 Avg=78.75 被加粗，而 PromptSRC 的 80.34 未加粗。**数据没有错，但排版强调可能被理解为全表最优。** 建议删除该单元格的加粗，或采用事先声明的统一表格规则；本轮未更动英文原表，以免在未经确认下扩大修改范围。

### P1：仍缺少 ImageNet 与部分近年相关方法的完整覆盖

当前的十数据集结论不能直接作为十一数据集榜单结果。现有引文主要为 2021—2024 年工作，新增 ATPrompt 2025 仅解决描述来源引文，不能替代对其他 2025—2026 年相关方法进行有针对性的文献更新。是否增加本地强基线或 ImageNet 需要按投稿时间、算力和研究主张另行决定。

### P2：方法细节可在补充材料完善

英语 Method 对预存描述的来源已经说明，但“valid descriptions”筛选与 token 级去重等实现细节仍比较简略；可在附录补充固定文本库和预处理规则。英文公式中的候选类别集合 $\mathcal C$ 也宜明确表示当前 Base 或 Novel 评估集合，以免被误解为把两个集合混合计算 softmax。中文对照稿已作此解释。

- 旧版中文摘要、方法、实验与 ImageNet 结果已从当前树删除；如需溯源只查看 Git 历史，**不要将旧数据或旧模型主张搬进当前投稿稿**。
