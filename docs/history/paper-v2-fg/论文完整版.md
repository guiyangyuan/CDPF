# TextConsistency: Multi-View Semantic Consistency for Few-Shot Image Classification

## Abstract

Few-shot image classification aims to recognize novel categories with limited labeled examples. Recent prompt learning methods like CoOp have shown promising results by learning continuous prompts for vision-language models. However, these methods rely on single static prompts that struggle to capture diverse semantic aspects of visual concepts. We propose TextConsistency, a novel framework that leverages multi-view semantic priors through knowledge distillation. Our method constructs multiple fine-grained textual descriptions for each class and employs an instance-adaptive aggregation mechanism to dynamically weight different semantic perspectives. During training, we use semantic consistency distillation to transfer rich multi-view knowledge into learnable prompts, while maintaining inference efficiency identical to CoOp. Extensive experiments on 10 benchmark datasets demonstrate that TextConsistency achieves competitive performance with state-of-the-art methods, particularly excelling on challenging tasks like action recognition (UCF101: +2.00%) and fine-grained classification (FGVC Aircraft: +0.39%), while requiring no additional computational cost during inference.

## 1. Introduction

### 1.1 Research Background

Vision-language pre-training models, particularly CLIP (Contrastive Language-Image Pre-training), have revolutionized few-shot learning by aligning visual and textual representations in a shared embedding space. These models enable zero-shot classification through natural language prompts, eliminating the need for task-specific fine-tuning. However, manually designed prompts often fail to capture the nuanced semantics required for diverse visual recognition tasks.


### 1.2 Motivation and Challenges

Recent prompt learning methods like CoOp learn continuous prompts through gradient descent, achieving significant improvements over hand-crafted prompts. However, these approaches face several limitations:

1. **Limited Semantic Coverage**: Single learnable prompts struggle to capture the multi-faceted nature of visual concepts (e.g., color, shape, texture, context).

2. **Generalization Gap**: Models optimized on base classes often overfit to specific semantic aspects, leading to poor generalization on novel classes.

3. **Static Representation**: Fixed prompts cannot adaptively emphasize different semantic dimensions for different input images.

### 1.3 Our Approach

We propose TextConsistency, a framework that addresses these challenges through three key innovations:

1. **Multi-View Semantic Priors**: We construct diverse textual descriptions covering multiple semantic dimensions (visual attributes, scenes, functions, etc.) for each class.

2. **Instance-Adaptive Aggregation**: A hierarchical attention mechanism dynamically weights different semantic views based on input image features, enabling instance-specific semantic emphasis.

3. **Semantic Consistency Distillation**: We employ knowledge distillation to transfer rich multi-view semantic knowledge into compact learnable prompts, maintaining inference efficiency.


### 1.4 Main Contributions

Our main contributions are summarized as follows:

- We propose TextConsistency, a novel framework that leverages multi-view semantic priors to enhance prompt learning for few-shot classification.

- We design a hierarchical view aggregation mechanism with fine-grained grouping that adaptively weights semantic perspectives based on input instances.

- We introduce semantic consistency distillation that transfers multi-view knowledge into learnable prompts without additional inference cost.

- Extensive experiments on 10 benchmark datasets demonstrate competitive performance with SOTA methods, with significant improvements on challenging tasks (UCF101: +2.00%, FGVC Aircraft: +0.39% over AnchorOPT).

## 2. Related Work

### 2.1 Vision-Language Pre-training

CLIP learns transferable visual representations by training on 400M image-text pairs with contrastive learning. The model consists of dual encoders that map images and texts into a shared embedding space, enabling zero-shot classification through similarity matching. CLIP's success has inspired numerous downstream applications in few-shot learning, domain adaptation, and multimodal understanding.
