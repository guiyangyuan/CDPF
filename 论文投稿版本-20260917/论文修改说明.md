# TextConsistency 论文修改说明

## 本轮完成结果

论文已经按实际代码与已审计实验重写为可继续投稿打磨的英文稿。最终稿题目为：

> TextConsistency: Parameter-Free Probability Fusion of Learned Prompts and Class Descriptions for Base-to-Novel Recognition

当前正文为 12 页 Elsevier `elsarticle` 预印本，包含方法公式、十数据集主结果、Base/Novel/HM 汇总、文献方法定位、组件消融、三种子稳定性、RTX 4090 推理效率和局限性说明。

## 与代码和结果对齐的核心表述

- 训练分支是 CoOp；冻结描述分支把同一类别的有效描述嵌入取均值并再次归一化。
- 推理使用固定 `0.5/0.5` 概率平均，不按数据集选择权重，不增加可训练参数。
- 统一使用 CLIP ViT-B/16、16-shot Base-to-Novel 协议；可训练方法报告 seed 1、2、3。
- 十数据集平均 HM：Zero-shot CLIP 71.88、CoOp 75.33、本地 CoCoOp 76.15、TextConsistency 78.75。
- TextConsistency 相对同批 CoOp 在 30/30 个种子级比较中提高 HM，相对本地 CoCoOp 在 10/10 个数据集提高 HM。
- 相对 CoOp，十数据集平均 Base 从 81.88 变为 81.58，Novel 从 70.50 提高到 76.44，说明主要收益来自 Novel 泛化。
- 组件平均 HM：CoOp 75.33、冻结描述 74.77、固定 logit 融合 78.37、固定概率融合 78.75。描述分支单独并不强，融合收益来自互补。
- RTX 4090、batch 64 实测从 90.128 ms/batch 增至 90.796 ms/batch，额外延迟 0.74%，新增可训练参数为 0。

## 文献对比边界

论文把本地复现和原论文报告值分成两张表。按共同十数据集重新计算，本文 78.75：

- 高于 CuPL 73.53、论文 CoCoOp 75.67、KgCoOp 77.10；
- 与 MaPLe 78.75 持平；
- 低于 PromptSRC 80.34。

这些文献数字不是本地复跑结果，只用于定位。当前结果可以支持“无新增可训练参数、很低额外推理成本、跨十数据集稳定改善、达到 MaPLe 水平”的结论；不能写成 SOTA、超过 PromptSRC，也不能保证录用。
